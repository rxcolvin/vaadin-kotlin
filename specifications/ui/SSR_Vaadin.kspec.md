# Overview
The Vaadin Flow framework is a Java-based SSR framework for building web applications. Karibu is a Koltin DSL for Vaadin Flow,
which will be used to build the UI for SSR_Vaadin applications via the Karibu Koltin specific DSL

# References
Vaadin Documentation: https://vaadin.com/docs/latest/getting-started
Karibu: https://github.com/mvysny/karibu-dsl
